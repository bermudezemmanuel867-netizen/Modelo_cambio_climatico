# 🌍 Dashboard de Impacto del Cambio Climático en México

Análisis exploratorio e interactivo sobre emisiones de CO₂, temperatura, almacenamiento de presas y su impacto en cultivos y desplazados climáticos (2013–2030).

### 🔗 Ver Dashboard en Vivo
👉 **[Abrir aplicación interactiva en Streamlit](https://streamlit.app)**

### 🛠️ Tecnologías utilizadas
* **Python** (Pandas, Statsmodels)
* **Plotly Express** (Visualización interactiva)
* **Streamlit** (Despliegue web)
